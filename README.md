# 异度装甲：一万年的回声

中文剧情与世界观阅读站。首周目按游戏推进，二周目加入完整真相与伏笔回收；人物与术语支持章节简介，阅读位置保存在当前浏览器。

## GitHub Pages

无需构建或在线 CDN。将本目录文件上传到专用仓库，在 **Settings → Pages → Deploy from a branch** 中选择发布分支与 **/(root)**。

资源均使用相对路径，支持 GitHub Pages 项目站点的子目录地址。`.nojekyll` 保留静态文件结构。

## 权限与阅读记录

GitHub Pages 的网站访问权限与仓库可见性分别设置。个人账号的 Pages 公开访问；私密发布需要 GitHub Enterprise Cloud 组织支持。原 Sites 的个人访问权限不会自动迁移至 GitHub。

阅读记录属于浏览器与站点域名。更换域名后，原域名保存的阅读位置不会自动转移；新站仍支持自动记录和续读。
